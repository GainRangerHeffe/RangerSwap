About RangerSwap

What it is, how it routes swaps, and what is not built yet

🧭

Project status

RangerSwap is a working swap front end and a set of contracts that have not been deployed. It is a prototype, not a live protocol.

  • Swaps: working, routed through liquidity that already exists on each chain.
  • Liquidity, pools and limit orders: interface only. They need RangerSwap's own contracts, which are not deployed.
  • V3 pools: planned.
🔀

How swaps are routed

Each chain is set to one liquidity source in tokens-data.js:

  • External router: an existing Uniswap V2 style DEX, such as PulseX on PulseChain.
  • Aggregator: the 0x Swap API, which finds the best price across many DEXs. Needs a 0x API key.
  • Own pools: RangerSwap's factory and router, once they are deployed and have liquidity.
💰

Fees

RangerSwap adds a 0.25% fee on top of the price from the liquidity source. The underlying DEX or aggregator charges its own fee as well.

The fee and the wallet that receives it are set in tokens-data.js. The receiving wallet is still a placeholder.

Security notes

  • The factory and router follow the Uniswap V2 design.
  • The limit order contract has an owner who can pause it.
  • Nothing here has had a third-party audit.
  • Swaps are sent from your own wallet. Check the token, amount and network in your wallet before you confirm.
